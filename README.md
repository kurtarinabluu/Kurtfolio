# Kurtfolio

Vue 3, TypeScript, and Tailwind CSS portfolio with bottle-green surfaces, sage and seafoam accents, and pale mint backgrounds.

Palette values live in `tailwind.config.ts`. The original `espresso`, `peony`, and `mauve` token names remain for compatibility with the components. Keep the shared layout and control styles in `src/style.css` when changing colors.

## Development

Run `npm install`, then `npm run dev` from this directory. Use `npm run type-check` for strict Vue and TypeScript checks. `npm run build` checks types before producing the production bundle; use `npm run preview` to preview it.
